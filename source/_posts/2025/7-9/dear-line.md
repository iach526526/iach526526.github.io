親愛的 Line：

我知道你總是把**始終陪伴在你身旁**掛在口中，但經過十三年的相處，我發現事情並不如你所說的這樣，你離我們**愈來愈遠了**。還記得第一次認識你的時候，是我為了玩《LINE cookie run》這款手機遊戲[^1]而開始使用你，從那時候我就該發現這一切都是你的控制欲使然，對於一款手機遊戲來說，我可以用 email 註冊、不註冊遊玩，為什麼我玩一個跑酷遊戲就非得安裝 Line 呢？國小的我並沒有識破你這不合理的行為背後的動機，是的，**你只是想藉由小遊戲一步步增加用戶人數**，這只是你的第一步。

## 我是從什麼時候開始離不開你的
因為我想玩跑跑薑餅人，所以我不得不註冊 LINE，在那之後為了有更多的愛心讓我可以賦予更多餅乾生命盡量救出所有餅乾們逃出魔女的烤箱[^2]，我爸爸和他的同事也加入和我一起玩，我的 LINE 帳號還從論壇加了很多很多的餅友一起互送體力。在這段時間我也接續下載了其他款需要 LINE 好友功能的遊戲：旅遊大亨、銀河特攻隊[^3]、熊大農場，這些遊戲無一例外都是要有更多好友體驗才會更好，我們全中了 LINE 的圈套。以旅遊大亨這個大富翁遊戲來說，玩遊戲難免會輸掉，輸掉就會掉積分，周獎品也會變少，遊戲提供了一個邀請好友訊息的功能，輸掉的時候透過遊戲選單傳旅遊大亨的下載連結給好友就可以抵掉一部分輸掉造成的損失，傳送對象在一定期間內還不能重複。

這些與 LINE 綁定的遊戲幾乎都有傳送遊戲下載邀請給朋友來獲得獎勵的機制，在我現在看來是一個很煩人的功能，我現在要是有這種其實不熟的好友每過幾天就會傳給我一個我根本不想玩的遊戲邀請連結，肯定會封鎖他。啊不過當時的玩家也有發現頻繁傳送邀請連結可能會導致他們被其他朋友討厭，所以有些人就會在論壇上開「空頭帳號」讓大家加為好友送這些垃圾訊息，所謂空頭帳號就是為了拿到邀請獎勵由玩家透過某種方式大量建立的帳號，創建方式我不太清楚，反正空頭帳號的名字會和一般帳號不太一樣，傳訊息也不會有真人收到。

當時是不曾聽過官方有明確禁止創立空頭帳號的行為，我想也是為了在數據上拉升 LINE 的用戶人數做的妥協[^4]，過了幾年以後，這些 LINE 遊戲相繼結束營運，最先出局的是跑跑薑餅人，它是第一款我持續遊玩就突然關服的遊戲，這讓我感到非常錯愕，買到手的餅乾突然就全都消失了，這是我第一次知道在別人的伺服器裡「買到」的數位產品其實並不是我的東西。

後來我開始玩妖怪手錶噗尼噗尼[^5]，就和 LINE 沒什麼直接關係了，只不過台灣相對大的玩家群組在 LINE 上面，才讓我繼續用 LINE 傳訊息，當時也沒覺得有什麼不對，就這樣一直用到國中畢業，直到我漸漸的不喜歡玩噗尼[^6]。

## 新寵——Discord
國中畢業後因為學校的資訊社團用的是 Discord 討論，我嘗試了這款新的軟體，他的分類頻道的介面實在讓我太驚艷了，在一個伺服器底下，可以依照主題劃分出不同的分類、頻道和討論串，甚至還能用程式自動分派身分組。對於和 LINE 在一起 9 年多的我來說，這種體驗完全是前所未有的：

- 在 LINE 裡，如果大家同時討論不同的事情，只能另外開小群聊，訊息很快就會被洗掉。
- 如果要標註特定成員，必須一個一個 `@`，非常麻煩。

但在 Discord 裡，這些問題都迎刃而解：

- 想分話題，直接新開一個公共頻道或討論串，大家自由選擇要不要加入。
- 管理員若有私密討論，也不必再拉一個新群，只要設定好**身分組與權限**就能做到。
- 要標註特定人群，不用用 `@All` 或逐一點名，只需要標註身分組。
- 一個群組內還能同時開好幾個語音通話分流

重點是：Discord**沒有廣告並且開放一定程度的使用者程式化功能**，讓我覺得有被當成一個正常使用者在被服務，他們的獲利方式主要是用戶用 Nitro 訂閱來提升體驗[^7]，Discord 提供明確的 API 文檔讓大家開發自己的聊天機器人[^8]，所以網路上寫 Discord bot 的資源就明顯比 Line bot 多，對初學者也比較友善。雖然不能把 Discord 的所有優點都拿去跟 LINE 比較來批評為什麼 LINE 沒有，因為最初的功能設計並不一樣，但我要說的是，Discord 的出現讓我知道在 LINE 上不好的體驗是可以被拿掉的，而不是所有人都得跟著 LINE 走。

## 刻意製造糟糕的用戶體驗
LINE，我拋棄你並不完全是我找到了更好的替代品，而是你的控制欲實在強到讓我無法忍受，在認識你這十多年的時間，你一年比一年還要胖，你已經是我手機裡面空間最大的 App ，你吃掉了我收到的所有照片，卻拒絕讓我查看他們；你進廠維修不是變得苗條也不是去除皺紋，而是加了很多不必要的功能，像是 LINE Today 、LINE Zoom、LINE TV、LINE VOOM ，你就不能專心的做好一個通訊軟體該做的事嗎？我打開 LINE 根本就不想看任何或長或短的影片或是八卦新聞，我只是要**在網路上聯絡我的朋友**。而你卻處心積慮的要我看廣告商投放的廣告，我知道你要賺錢，但是吃相太難看啦，網路上那麼多開源甚至是半付費[^9]的軟體可以用，我一點都不喜歡你？你只是贏在早早進入市場，還有一大批無法即時學習新軟體的用戶走不掉而已，總有一天所有人都會看清你的本相，離你而去。

[^9]:例如 Discord 的會員自由購買制
### 電腦版功能破碎

你根本無法好好為其他人著想，你總是強迫大家配合你的步調來和你相處，我在電腦上永遠無法使用到 LINE 的完整核心功能，某些貼圖無法在電腦顯示，字體小不拉機，裝置兼容還很差。LINE Chrome 擴充套件版甚至是不能使用社群聊天室，我總是在電腦版看到請到手機版查看的對話框，幹得好，你做了電腦版只是顯示對話框叫用戶他們去用手機開，這麼「優質」的軟體，**下次別做了**，請從我的視線消失。

最近一次我最無法忍受的引爆點是你打算停止瀏覽器擴充套件版本支援，更離譜的是：你無視了大家的回饋，只是把停止支援日期到延到 2026 安撫大家，這種朝四暮三騙猴子的伎倆我可不買帳。**LINE 的無障礙支援就是一陀大便**，用瀏覽器版本至少它用的是網頁，還能靠基礎的螢幕朗讀功能讓視障者有辦法讀訊息，現在你關掉這個功能，請問你可有要讓電腦版 LINE 的功能變得更好嗎？如果電腦版已經做到良好跨裝置和無障礙支援，那你要不要繼續擴充套件版隨你的便。但問題就是沒有，LINE 我用了超過十年還是這個鳥樣子。

### 裝置兼容性差
這和上一點電腦版功能破碎搭配在一起簡直是決殺，Linux 系統快要沒有不用虛擬機或容器來模擬 Windows 打開 LINE 的原生方式了，要是 LINE 哪天突然不支援你新買的裝置也是遲早的事。逼的你不得不用他的原本功能最完整的 App 。如果你懂一點程式設計就會知道維護手機 App 比網頁、桌面程式都還要麻煩的多，這種繞了灣耗費開發人力的行為也讓我感到十分困惑，好消息是：我在[資訊人權貴ㄓ疑](https://ckhung0.blogspot.com/2023/02/mobile-app.html)這個 blog [^10]找到了答案：

[^10]:此網站的作者現在是我們學校通識課的老師，他在 114 學年度上學期有開[資訊科技與媒體識讀](https://onepiece.nchu.edu.tw/cofsys/plsql/Syllabus_main_q?v_strm=1141&v_class_nbr=5032)，如果你和我一樣是中興大學的學生推薦你去修這門課，我看了課表覺得很紮實，是一門好課，只不過我必修衝堂沒辦法去。

- 在主畫面 (home screen) 搶到一席之地，你會比較有機會點開
- 一般人比較不會用擴充套件擋掉 App 內廣告
- HTTP 無狀態特性不利於紀錄每位用戶的使用習慣
  - App 可以全天觀察用戶。包括什麼時候打開、開多久。
  - 手機 App 有機會拿到更高的周邊硬體權限，而且一旦拿到後沒辦法自動關閉
- App 內嵌瀏覽器可以追蹤你瀏覽其他網站的習慣
  - 如果在電腦上就一定會打開你預設的外部瀏覽器


> (在自由軟體的小世界之外) 程式設計師的需求跟使用者的需求並不是決定資訊科技走向的最重要因素； 商業需求才是最大的驅動力。 而注意力經濟年代，最強大的商業需求就是抓住用戶的注意力， 以及蒐集用戶的行為資訊。這是監控式資本主義下的商業叢林競爭法則。 


## 再見，再也不見
LINE，真搞不懂為什麼還是有那麼多人喜歡你，你就是個蠻橫霸道的雲端領主，你提供的服務並不會讓世界進步，你為使用者創造了不便利，並利用這個不便利性賺取雲端租金，你服務的對象完全就是廣告商，你就是專有軟體大便化（Enshittification）最好的案例，更諷刺的是會還在一些提倡開源的資訊社群看到你的徵才攤位[^12]，LINE 本身就是開源精神無法被落實的高牆，這實在太荒謬了，周處除三害的下一部電影給 LINE 當主演當之無愧。

[^12]:小聲說，就是那個在每年三月在中研院舉辦的 S 開頭年會。希望我明年還能平安的走出會場
### 替代方案
依我看，去中心化的通訊軟體 SimpleX 和 matrix 的使用邏輯並不適合一般人，推廣不易；Discord 主軸是在社群，如果你只是要個人聯絡用會有一大片用不到的面板，並且他的介面分層比較複雜一些些，可能也不是很適合所有人；Telegram 只有客戶端開源，並不保證其他使用者訊息不會被拿去做資料分析。 

**[Signal](https://signal.org/zh_HK/download/)** 是個比較理想的方案，它[完全開源](https://github.com/signalapp)[^11]，支援端對端加密，介面也非常乾淨直白，甚至還有發限時動態的功能，這意味著 IG 也可以刪了，反正多數人只會在個人主頁放幾張不明所以的自拍、背影照，而主要貼文都放在限動鎖摯友，一般人根本沒有也沒有能力拍出那麼多好看的攝影照片可以 PO 到上面。你根本就不需要 instagram 其他的功能，這軟體在最初甚至只是純圖片分享網站。Signal 的限動就能滿足這需求，也能限定誰看得到，不必忍受 Instagram 混亂不堪的畫面，還不用從廣告垃圾堆中找朋友的限動，實在是太完美了！

![signal 乾淨的畫面](https://img.iach.cc/2025/7-9/dear-line/Signal.webp)

[^11]:代表你可以安裝你信任開發者的介面就可以串上伺服器，不像 LINE 永遠只能用他的軟體，因為後端技術不公開

### 你該停止使用 LINE 的理由

- 廣告很多
- 任何作業系統的電腦版相容不佳
- 手機版存在過多冗餘功能
- 它只想逼你裝 App 監視你
- 它會讓存在你裝置上的照片影片全都過期

你各位啊，此刻就開始進入替換 LINE 軟體的過渡期吧，趁現在你還可以用 LINE 通知你的所有朋友到其他平台聯絡你；趁著最近這波 LINE 漠視視障使用者權益的時候，轉貼相關[新聞](https://today.line.me/tw/v3/article/oq7Owr6)說服你的朋友慢慢離開這個專有軟體牢籠。

你不需要立刻把 LINE 刪除，只要踏出第一步率先和周圍的朋友們試著走出 LINE，這種社交通訊不像瀏覽器、密碼管理器或作業系統，我知道這個公司政策不好、體驗糟糕我個人隨時能離開棄用，但是通訊軟體它需要兩個人以上的遷移才算成功。所以，請從你親近的家人朋友開始，現在就行動！
